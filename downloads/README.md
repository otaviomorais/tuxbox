# TuxBox Dev 1.1.0

APK experimental e código-fonte completo das melhorias de gestão, terminal e interface.

- [Baixar APK](https://github.com/otaviomorais/tuxbox/raw/refs/heads/codex/download-tuxbox-dev/downloads/tuxbox-1.1.0-dev.apk)
- [Baixar código-fonte](https://github.com/otaviomorais/tuxbox/raw/refs/heads/codex/download-tuxbox-dev/downloads/tuxbox-fonte.zip)
- [Validação e limitações](VALIDACAO.md)

Android 10 ou superior. Aplicativo TuxBox Dev, ID `sh.tuxbox.root.dev`, assinado com chave de desenvolvimento. Pode coexistir com a versão normal, mas compartilha seus rootfs. Use um clone para experimentar.

Esta branch serve apenas para disponibilizar os arquivos gerados. O ZIP contém o código atualizado, as licenças, os scripts de build e os helpers. O código na raiz da branch permanece na base original.
