# Third-party terminal components

The Java sources in this directory are adapted from the terminal components of
[Termux](https://github.com/termux/termux-app), principally its
`terminal-view` and `terminal-emulator` modules. `WcWidth.java` is also based
on [termux/wcwidth](https://github.com/termux/wcwidth).
