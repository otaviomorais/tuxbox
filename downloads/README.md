# TuxBox Dev 1.1.0

- [Baixar APK em ZIP (10,4 MiB)](https://github.com/otaviomorais/tuxbox/raw/refs/heads/codex/download-tuxbox-dev/downloads/tuxbox-apk.zip)
- [Baixar código-fonte completo](https://github.com/otaviomorais/tuxbox/raw/refs/heads/codex/download-tuxbox-dev/downloads/tuxbox-fonte.zip)
- [Validação e limitações](VALIDACAO.md)

Baixe `tuxbox-apk.zip`, extraia `tuxbox-1.1.0-dev.apk` e abra o APK no Android. A versão requer Android 10 ou superior.

Aplicativo TuxBox Dev, ID `sh.tuxbox.root.dev`, assinado com chave de desenvolvimento. Pode coexistir com a versão normal, mas compartilha seus rootfs. Use um clone para experimentar.

O ZIP preserva exatamente o APK testado. SHA-256 do APK extraído: `88d5f6653ff23cba25fd40ada88f6aea1fa95ecd4be96d1262a63f59860f6034`.

Os checksums dos dois ZIPs estão em [SHA256SUMS](SHA256SUMS).

Esta branch disponibiliza os arquivos gerados. O ZIP do código-fonte contém o código atualizado, as licenças, os scripts de build e os helpers. O código na raiz da branch permanece na base original. A entrega dos ZIPs não depende de GitHub Actions.
